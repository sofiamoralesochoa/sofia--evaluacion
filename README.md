# Explora colombia 
esta página web se hizo o fue desarrollada con react combinada con vite, conectada con la página Api colombia que es pública (https://api-colombia.com/api/v1)
en la página web se encuentra información sobre todos los departamentos que hay en colombia, donde se agregó, una barra espaciadora para buscar facilmente el deprtamento deseado con su respectiva información sobre del departamento.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)
